# ADR 0001：使用 LangGraph 作为 Agent 编排层

- 状态：Accepted
- 日期：2026-09-14

## 背景

项目需要状态化工具调用、条件路由、中断恢复、人工确认和流式事件。完全自研运行时会消耗大量工程时间，低代码平台又会削弱领域逻辑的可控性和代码所有权。

## 决定

使用 LangGraph 作为 Agent 编排层。领域状态、工具契约、安全策略、RAG、API、评测和部署由本项目实现。LangGraph 对象不得渗透到领域工具核心接口中。

## 后果

- 可以直接使用状态图、checkpoint 和 Human-in-the-loop 能力。
- 团队需要边实现边学习 LangGraph。
- 必须通过适配层维持框架可替换性。
- M3 之前保持单 Agent，不因框架示例提前引入多 Agent。
