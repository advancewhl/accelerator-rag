## 提交隔离

- `pyproject.toml` 只提交 RAG 的 HTTP 依赖和 Web 资源打包；Agent／MCP 依赖与入口留在工作区。
- README、里程碑和导航只提交 RAG 部分，原 Agent 工作保留。
- Model Provider 使用独立的可选调用上下文，旧 Agent 的已加载预算模块仍兼容；不提交 Agent 图、工具或预算实现。
- `config/settings.json`、通用配置类中的 Agent 扩展、Waveform、MCP、相关发布包及其它业务记录不纳入提交。
- 第三方本地前端资产保留许可证与来源；补充 PDF.js `build/` 的忽略规则例外，保证核心模块和 worker 随源码与 wheel 分发。文件数不等于业务模块数。
