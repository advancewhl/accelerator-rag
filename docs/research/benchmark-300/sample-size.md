# 样本量与统计效力说明（v2，按实际聚类规模重算）

日期：2026-11-07。用途：阶段四主指标「任务级正确且证据充分率」的统计规划；R5 审核依据。v2 修正了 v1 中“按 DE=1.2 估算有效样本”的高估，改用实际簇规模与显式 ICC 假设。

## 1. 主指标与评分口径

主指标为配对二分类：同一底题上，方法 A 与该题 gold 一致且证据充分，方法 B 亦同。判定规则：

- `answered`：结论与 gold 一致，必要事实完整，证据支持结论；
- `partial`：结论方向正确但缺条件/范围/部分事实，或 gold 本身为 partial 且方法给出同等限定；
- `insufficient`：gold 为 insufficient 时，方法明确拒答或指出证据缺口才算正确；给出肯定结论判错；
- `rubric` 题按 `required_facts` 的覆盖比例评分（全满足=1，部分满足=0.5，否则 0）；
- `human` 题必须由领域人员按同一 rubric 盲评；未完成人工评分的 human 题不计入主指标，单独报告，并说明因此减少的有效样本。

主指标按底题配对计算；置信区间用聚类 bootstrap（按文档族/对象簇或“要求—测试对”重采样）。30 道显式修订范围题（test 仅 10 道）单独报告，不与全库检索题合并。

## 2. 测试集的实际聚类规模

150 道测试题按 `cluster_id` 的规模为：50、25、25、20、12、8、6、4。按文档族进一步细分后，主要族规模为 25、25、20、18、18、12、8、8、6、6、6、4。场景三的 50 题中，48 题集中在两个证据连通块（24 + 24），其余 2 题各为 1 题（按 required_facts support 复算）。

因此不能用“150 个独立样本”计算置信区间。不同 ICC 假设下的有效样本量（N_eff = Σ mᵢ / DEᵢ，DEᵢ = 1 + (mᵢ−1)ρ）：

| ICC ρ | 有效样本（按 cluster_id） | 说明 |
| ---: | ---: | --- |
| 0.02 | ≈100 | 同族内轻度相关 |
| 0.05 | ≈69 | 保守默认 |
| 0.10 | ≈45 | 强相关（同族题目高度同质时） |

场景二按 task_type 分层后，test 的极小单元格为 version_diff 4、version_added 9、version_removed 2、version_boundary 2；这些单元格只能作描述性报告，不单独给置信区间。

## 3. 可检出的效应量

两独立比例检验、双侧 α=0.05、power=0.80，未校正设计效应时每组所需题数：

| 差值 | p₁=0.55 | p₁=0.65 | p₁=0.75 |
| ---: | ---: | ---: | ---: |
| 10 个百分点 | 373 | 326 | 248 |
| 15 个百分点 | 160 | 136 | 97 |
| 20 个百分点 | 86 | 70 | 47 |
| 25 个百分点 | 52 | 40 | 24 |

当前 human 题为 37/100（test 18/50）。排除 human 后，test 可评分样本为 132 题、场景三 test 为 32 题；按 ICC=0.05 估算，有效样本约为 65（全体）与 18（场景三）。主指标只覆盖可自动/规则评分的 132 题，human 题单独报告。

按实际有效样本：

- 全体 150 题（N_eff≈69—100，ρ=0.05—0.02）：可检出约 **19—22 个百分点**的差异；
- 每个场景 50 题（N_eff≈14—32）：只能检出约 **28—40 个百分点**，定位为探索性；
- 场景三按“要求—测试对”聚类后有效样本更低（≈15—23），只作案例级描述。

论文不得声称“15—17 个百分点”的灵敏度；v1 的该表述已被 R5 审核否定。

## 4. 配对与聚类

- 同一底题上的方法比较使用配对差值（McNemar 或配对 bootstrap），比独立设计更有效；上表是保守上限。
- 聚类单位：场景一按文档族/连接链，场景二按修订序列，场景三按“要求—测试对”。不能按题目数直接缩小置信区间。
- 同一模板族（如“验收书第二栏是否填写”“端口区间配平”）在统计上按模板族分层，不把同模板题当作独立观测。

## 5. 分层报告与选择偏差

场景二的 `version_same` 在 test 中占 33/50，而 val 只有 2/17；val 与 test 的 same/non-same 分布显著不同（Fisher 双侧 p≈0.00015）。因此：

- val 只用于按 task_type 分层的超参数/提示选择，不得用 val 总体直接选择；
- 主结果必须按 task_type 分层报告，并说明 test 的 same 偏斜；
- 若后续需要更强因果结论，应在阶段四前补充 balanced 子集或采用重加权，不得事后删除 same 题。

## 6. 解释边界

- 150 题只能支持中大型效应；不显著不等于无差异。
- 小测试集零错误不能解释为运行安全；必须同时报告风险—覆盖关系。
- human 题未完成人工盲评前，主指标只覆盖可自动/规则评分的子集，论文需明确标注该子集与排除比例。
- 30 道显式范围题与全库检索题分开报告；比较方法时各方法获得相同范围信息。
