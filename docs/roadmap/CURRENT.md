# 当前 RAG 里程碑

## 当前阶段

截至 2026 年 10 月 28 日，独立 RAG 已实现并部署四阶段证据闭环，生成模型为 `ds-1017`。统一导航见 [RAG 文件导航](../rag/README.md)，相对上次提交的范围见 [变更说明](../rag/changes-since-4099ce1.md)。

当前入口为 `python -m accelerator_rag.rag` 和独立 HTTP 服务。通用检索 CLI 仍默认使用 BM25；两个入口分别保留。业务流程不运行 Agent 图或 Waveform 工具，模型适配器使用共享消息及预算组件。

## 当前交付

- 文档问答、证据引用、版本与物理页、只读知识库目录和页内 PDF 阅读。
- 检索前拆题；BM25 与双路语义召回、同版本同页补全和统一重排。
- 按需求覆盖、冲突及开销选择子集；字段清单绑定原文条目。
- 分开核查事实真实性与需求完整性，保留部分真实事实，缺项定向补检索。
- 最多 2 轮检索，最终证据最多 5 个父块和 6,000 个证据 token；请求级过程记录。
- 独立 GPU 容器、本机 systemd 转发和断线重连。

## 验证与剩余限制

149 项 RAG、Provider 和 BM25 联合回归通过；其中还包含 Waveform Provider 测试，不能全部计为 RAG 专属测试。36 题正式 HTTP 完整回归用于诊断，最后两项修复后复测 6 题，完整过程见 [验收报告](../../reports/rag-framework-20261028.md)。

完整回归的 21 道正例中，首轮 Top-5 完整覆盖 19 题，Top-20 和最终所选子集完整覆盖 21 题；11 道负例全部拒答。指标来自开发集与最后两项修复前的全量记录，最终代码尚未重跑全部问题。召回、引用覆盖和回答正确性分别评价，口径见 [指标复核](../../reports/rag-framework-20261028/retrieval-metrics.md)。

当前仍有精确参数比较符表达不足的案例。生成与核查使用同一模型服务；有限检索与证据预算仍可能漏项。尚需扩大独立测试集，并执行独立人工语义评分。

2026 年 10 月 22 日的 `4099ce1` 完成 Stage 2.8.2：E5／Qwen3 各取前 10 个规范父块，Qwen3 重排后保留前 5 个。固定 21 道正例中完整 Hit@5 为 20／21，完整证据口径 MRR@5 为 0.6071；唯一未完整命中为 IOC 启动信息。见 [历史重排报告](../../reports/rag-stage-two-eight-two-reranking.md)。
