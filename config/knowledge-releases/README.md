# 知识库发布配置

本目录保存发布模板与 Schema，**不保存凭据、模型密钥或服务器地址**。实际发布包放在 `/opt/accelerator-rag-releases/<release-id>/`，由发布流程生成并冻结。

## 发布号

`kb-主版本.次版本.修订号`，候选加 `-rc.N`：

- 主版本：不兼容契约变化（例如身份/API 语义变化）；
- 次版本：语料扩充或查询能力变化；
- 修订号：兼容修正；
- 每次重建使用独立 `build_id`；已发布目录不改名、不覆盖。

## 模板

`kb-2.0.0-candidate.template.json` 是**模板**，尖括号为待填值，不是可运行配置。候选构建完成后由 `scripts/kb2_candidate_build.py`（K4）生成实际清单；模板中的字段必须与生成器一致。

## 必须包含

发布身份、代码/环境快照、语料范围、处理契约、两路检索配置、回答配置、验证材料、运维与回滚目标。缺少任一关键部分时，清单状态必须是 `candidate-incomplete`，不能标记为 `accepted` 或 `live`。
