## 2. 验证口径

题集为 `validity-pilot-v2`，修订号 `2026-10-29-r1`。50 题包括 10 道旧 PDF 对照和 40 道新 Markdown 题。预期为 45 道完整回答、3 道部分回答和 2 道证据不足。题集与文档同源，且代码来自未提交工作区，因此仅作为开发诊断。

本轮直接调用已切换的生产服务，客户端仅发送 `query`。标准答案、必要事实和引用标注不传给服务。未针对本轮回答调整提示词、检索或生成代码，也不靠重复提问挑选更好的答案。

检查分为三层：HTTP 执行结果；父块覆盖和引用位置；回答与评分清单的逐题比对。状态一致、引用定位正确和语义正确分别记录。助理初审不作为独立人工评分，双人审核仍待完成。

## 4. 对下一步计划的影响

首先统一评分口径，再做方法改动。具体澄清与下一版题干建议见[评分裁决清单](rubric-adjudication.md)。本轮不改旧题、不重算成更高分，也不把近似同源问题当作独立样本。

优先验证三个最小改进：保留比较关系；把题目输入代入文档条件；区分“未提供证据”和“事实不存在”。另行检查必要字段及指代是否完整。先与明确的提示词和规则基线比较，再决定是否需要有效性边界表示。

10 道版本题的固定证据全部进入最终集合，且多数回答保留了部署未知与历史归因边界。本轮仍不支持宣称依赖传播或动态版本维护已有必要性或收益。H2 需要另做真实变更回放，不能由静态问答得分替代。
