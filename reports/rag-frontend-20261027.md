# Standalone RAG 前端重建验收

日期：2026-10-27。

前端已重建并同步到 GPU 主机的现有部署。PDF 引用现在直接进入页内阅读器，不再打开新标签页。当前生成模型接口返回认证错误，因此本次不能宣称真实问答端到端通过。

## 界面与交互

- 左侧显示本次页面中的查询记录，支持回看和新建查询。刷新页面后记录清空。
- 中间显示问题、回答、依据状态和复制操作，底部固定提问框。
- 右侧显示文档名称、版本、物理页和原文摘录。点击引用编号或“阅读原文”，在同一页面打开 PDF。
- 阅读器支持翻页、指定页码、缩放、适合宽度、展开阅读和返回证据列表。切换文档会取消旧的加载与渲染任务。
- 手机端将证据排列在答案下方，PDF 使用页内阅读视图；返回时恢复页面滚动位置。
- 继续使用本地 Markdown、KaTeX 和 PDF.js 资源，没有新增公网依赖。问答请求仍只发送当前问题。
- 区分模型认证失败、服务繁忙、证据校验失败和输入错误，保留问题供重试。

## 当前限制

生产问答返回 HTTP 502，响应码为 `AUTH`。模型接口直接请求返回 HTTP 401。RAG 既有凭据与模型容器环境配置一致，本地保存的既有凭据也返回 HTTP 401。未更改模型服务或其认证配置，也未重启任何容器。

因此，本次确认的是前端部署、静态资源、真实 PDF 服务及历史响应的界面交互；新的真实回答尚未验收通过。需要恢复模型服务的有效认证后，再复验实时问答链路。
