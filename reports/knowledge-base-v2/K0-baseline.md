## 6. 已知限制与风险

1. **旧语料缺失**：无法在本工作区验证“旧 17 份迁移后问答不退化”。K4 的完整候选构建必须移到生产机或补回原文。
2. **无 GPU / 无模型目录**：无法本地构建双路索引，也无法运行真实 embedding/reranker 回归。
3. **无 OCR 工具**：17 份扫描件只能先做页面分类与等价文本核对，不能宣称 OCR 已完成。
4. **LibreOffice 沙箱限制**：历史报告记载沙箱内启动失败；DOC 转换适配器必须显式报告环境失败，不得伪造成功。
5. **日期与批准状态未知**：网络安全报告封面日期晚于计划日期、V6 标注“返回通读版本”；这些材料只能作为待核实/参考，不能自动升为现行。
6. **旧索引 payload 无 Schema v2 字段**：K3 的显式版本筛选需要重建候选索引；默认查询保留旧 payload 兼容路径，但不能用“先取前 N 再过滤”冒充版本筛选。
7. **发布清单尚不存在**：本次只建立发布身份与目录最小契约；`release-manifest.json` 的完整生成属于 K4/K6。
